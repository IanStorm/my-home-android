# My Home - Android 📱

Garage project for **private purposes**.
Centralizes and simplifies setup for Android devices in my home.


## How to develop? 👨‍💻 👩‍💻


### ...via Docker 🐳 and Visual Studio Code

1. Clone this repository
2. Open the cloned repo in VSCode
2. Install the recommended extensions
2. Press <kbd>F1</kbd> and choose `Dev Containers: Reopen in Container`
	1. Install dependencies: `npm clean-install`
	2. Execute all quality checks: `npm test`
	2. Start development: `npm run dev` 🤘
